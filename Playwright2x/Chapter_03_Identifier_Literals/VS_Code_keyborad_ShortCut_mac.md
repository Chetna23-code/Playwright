# VS Code Keyboard Shortcuts - Mac

## General

| Action | Shortcut |
|--------|----------|
| Command Palette | `Cmd + Shift + P` / `F1` |
| Quick Open, Go to File | `Cmd + P` |
| New Window | `Cmd + Shift + N` |
| Close Window | `Cmd + Shift + W` |
| User Settings | `Cmd + ,` |
| Keyboard Shortcuts | `Cmd + K, Cmd + S` |

## Basic Editing

| Action | Shortcut |
|--------|----------|
| Cut line (empty selection) | `Cmd + X` |
| Copy line (empty selection) | `Cmd + C` |
| Move line up/down | `Option + Up/Down` |
| Copy line up/down | `Shift + Option + Up/Down` |
| Delete line | `Cmd + Shift + K` |
| Insert line below | `Cmd + Enter` |
| Insert line above | `Cmd + Shift + Enter` |
| Jump to matching bracket | `Cmd + Shift + \` |
| Indent/outdent line | `Cmd + ]` / `Cmd + [` |
| Go to beginning/end of line | `Cmd + Left/Right` |
| Go to beginning/end of file | `Cmd + Up/Down` |
| Scroll line up/down | `Ctrl + Up/Down` |
| Scroll page up/down | `Option + PgUp/PgDn` |
| Fold/unfold region | `Option + Cmd + [` / `Option + Cmd + ]` |
| Fold/unfold all | `Cmd + K, Cmd + 0` / `Cmd + K, Cmd + J` |
| Add comment | `Cmd + K, Cmd + C` |
| Remove comment | `Cmd + K, Cmd + U` |
| Toggle line comment | `Cmd + /` |
| Toggle block comment | `Shift + Option + A` |
| Toggle word wrap | `Option + Z` |
